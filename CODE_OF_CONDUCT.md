# Code Of Conduct

## Our Pledge
We want this project to be a welcoming, practical place to collaborate on local-first AI tooling, memory infrastructure, and MCP integrations.

Contributors, maintainers, and users are expected to act with respect, patience, and curiosity.

## Expected Behavior
- Be respectful and constructive
- Focus criticism on ideas and implementations, not people
- Assume good intent, especially when debugging unfamiliar setups
- Share context clearly when reporting bugs or design concerns
- Help keep the project safe by avoiding public disclosure of sensitive details

## Unacceptable Behavior
- Harassment, intimidation, or personal attacks
- Discriminatory language or exclusionary behavior
- Publishing secrets, private logs, or exploit details irresponsibly
- Repeatedly derailing technical discussions

## Enforcement
Maintainers may edit, hide, or remove content that violates this code of conduct and may restrict participation when necessary to protect the project and its contributors.

## Reporting
For routine behavior concerns, use the normal repository support path in [`SUPPORT.md`](SUPPORT.md).

For security-sensitive concerns, follow [`SECURITY.md`](SECURITY.md) instead of posting details publicly.
