4 步 开始

# 1. 克隆
git clone https://github.com/passionworkeer/obsidian-shared-memory-bus.git
cd obsidian-shared-memory-bus

# 2. 安装依赖
npm install

# 3. 启动 MCP 服务器
node start.js            # 或 Windows 双击 start.bat

# 4. 配置 Claude Code（自动写入 .claude/mcp_servers.json）
node setup-mcp.js

重启 Claude Code / Codex / Cursor，
MCP 工具列表里就会出现 memory_recall / memory_store / memory_search。
