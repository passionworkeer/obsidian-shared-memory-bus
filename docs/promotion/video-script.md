## 录制注意事项

1. **环境准备**：开拍前务必把 vault 记忆数据填好（至少几十条真实条目），检索演示才好看。`search_shared_memory` 必须能返回 vault 真实数据（entryCount 应 > 100）。
2. **终端美化**：用一致的终端主题（深色背景、清晰字体），命令行字号调大到录屏可读。建议用 Windows Terminal 或 iTerm2。
3. **演示真实性**：3.6 镜号的 score 数字（1.015/0.999/0.971）和 entryCount 143 是真实实测值，直接录真实输出即可，不要造假。
4. **节奏控制**：段落 3 实机演示是核心，宁可多录、剪辑时剪短，不要念稿式硬演。段落 4 特性卡可用快剪保持节奏。
5. **配乐**：建议轻快电子/lo-fi 纯音乐底噪，旁白音量高于配乐。hook 段（1.x）可静音制造反差。
6. **字幕规范**：旁白关键短句上字幕，演示命令行单独上"操作字幕"（区别样式），避免两套字幕打架。
