# Support

1. Read [`README.md`](README.md)
2. Check [`docs/INSTALL.md`](docs/INSTALL.md)
3. Check [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)
4. Check [`docs/FAQ.md`](docs/FAQ.md)

## Open A Bug Report When
- a documented command fails
- a shared MCP service does not become healthy
- the runtime behaves differently from the docs
- a previously working integration regresses

Include:
- your Windows version
- the command you ran
- sanitized output from `shared-mcp/status-shared-mcp.ps1`
- whether the problem is reproducible in a fresh session

## Open A Feature Request When
- you want support for a new agent
- you want to share or isolate a service differently
- you want a new validation, install, or operations workflow

## Security Issues
Follow [`SECURITY.md`](SECURITY.md). Do not post exploit details or real secrets publicly.
